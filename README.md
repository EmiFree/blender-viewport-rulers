# Blender Viewport Rulers
An addon for Blender that adds configurable Microsoft Word style rulers to the viewport. 

<img width="2818" height="1354" alt="image" src="https://github.com/user-attachments/assets/693b9ca0-21ec-4bb6-9592-2bcb9e0151d8" />

## Configurable in the *n menu*
Offset to avoid falling behind other UI elements can be set, alongside size, color, and opacity.
