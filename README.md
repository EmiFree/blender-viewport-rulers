# Blender Viewport Rulers
An addon for Blender that adds configurable Microsoft Word style rulers to the viewport. Works most accurately in orthographic mode.

<img width="2818" height="1354" alt="image" src="https://github.com/user-attachments/assets/693b9ca0-21ec-4bb6-9592-2bcb9e0151d8" />

## Configurable in the *n menu*
* Enable and disable rulers on the top, bottom, left, and right
* Change color, opacity, offset, and thickness
